## 一、源系统网关

| 网关类型 | 地址 | 适用接口 |
|----------|------|----------|
| 旺店通奇门 | `http://3ldsmu02o9.api.taobao.com/router/qm` | 出入库、售后退单 |
| 慧经营 | `http://332wh0cyoi.api.taobao.com/router/qm` | 直播利润、营销分摊 |
| 旺店通 OpenAPI | `http://wdt.wangdian.cn/openapi` | 仓库档案 |
| 微伴 | `https://open.weibanzhushou.com` | 客户-员工关系 |

### 认证方式

| 网关 | 说明 | 实现参考 |
|------|------|----------|
| 奇门 | Query 参数 + form Body；`wdt_sign` + TOP `sign` | `connectors/wdt/sdk/sign.py`、`connectors/wdt/sdk/client.py` |
| 慧经营 | 奇门协议 + Body 内 `hjySign` | 各 `connectors/wdt/sdk/api/*.py`（慧经营类） |
| OpenAPI | Query 参数 MD5 签名 | `connectors/wdt/sdk/openapi_client.py` |
| 微伴 | `access_token`（先 POST 换 token，再调业务接口） | `connectors/weiban/sdk/client.py` |

奇门请求要点：

- HTTP 方法：**POST**
- Query： `app_key`、`method`、`timestamp`、`sign`、`v=2.0`、`format=json`、`sign_method=md5`、`target_app_key` 等
- Body：`application/x-www-form-urlencoded`，含 `params`、`pager`、`datetime`、`wdt_appkey`、`wdt_salt`、`wdt3_customer_id`、`wdt_sign`
- `timestamp` 格式：`yyyy-MM-dd HH:mm:ss`（与 Body 中 `datetime` 一致）

## 三、任务参数与调度策略

### 3.1 公共参数字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `past_value` | int | 相对当前时间回溯量 |
| `past_unit` | string | `day` / `hour` |
| `start` / `end` | string | 固定日期范围（`YYYY-MM-DD` 或带时间），与 `past_*` 二选一 |
| `interval` | int | 拉取切窗间隔（秒）；如 `3600` 表示按小时分段请求 |
| `page_size` | int | 分页大小 |
| `workers` | int | 并发线程数 |
| `terms_income` | string | 直播利润接口业务参数（见任务 5、6） |
| `after_pull_dwd` | bool | 拉取完成后执行 ODS→DWD 清洗（见第五节） |

### 3.2 各任务运行参数

| 任务 | past | interval | page_size | workers | 其他 |
|------|------|----------|-----------|---------|------|
| 退货入库日批 | 2 day | 3600 | 200 | 3 | — |
| 销售出库日批 | 2 day | 3600 | 200 | 3 | 单次请求时间窗 ≤ 60 分钟 |
| 售后退单日批 | 3 day | 3600 | 200 | 3 | after_pull_dwd=true |
| 微伴客户 | — | — | 200 | 3 | 无时间范围；依赖 EHR 员工列表 |
| 直播正向 | 2 day | — | 200 | 1 | terms_income=3；after_pull_dwd=true |
| 直播逆向 | 2 day | — | 200 | 1 | terms_income=3；after_pull_dwd=true |
| 营销账单分摊 | 2 day | — | 10000 | 3 | — |
| 销售出库小时批 | 1 day | 3600 | 200 | 3 | — |
| 退货入库小时批 | 1 day | 3600 | 200 | 3 | — |
| 售后退单小时批 | 1 day | 3600 | 200 | 3 | after_pull_dwd=true |
| 仓库档案 | 3 day | — | 200 | 10 | — |

### 3.3 调度时间线

| 时刻 / 频率 | 任务 |
|-------------|------|
| 04:00 | 售后退单日批、微伴客户 |
| 06:00 | 直播正向、直播逆向 |
| 08:00 | 退货入库日批、销售出库日批 |
| 09:00 | 仓库档案 |
| 10:30 | 营销账单分摊 |
| 每 1 小时 | 销售出库小时批、退货入库小时批、售后退单小时批 |

## 八、OpenAPI 接口定义

每个源接口均有 OpenAPI 3.0 JSON 定义，路径：

```text
docs/openapi/apis/
```

按网关汇总：

```text
docs/openapi/bundles/wdt-qimen.json
docs/openapi/bundles/wdt-hjy.json
docs/openapi/bundles/wdt-openapi.json
docs/openapi/bundles/weiban.json
```

接口字段、Query/Body 结构以 OpenAPI 文件与 SDK 源码为准。

## 九、附录：CLI 调用示例

与现网调度等价的命令行（供联调）：

```bash
# 销售出库日批
python run.py pull -c wdt -s stockout_sales_query_with_detail \
  --past 2 --past-unit day --interval 3600 --page-size 200 --workers 3

# 售后退单日批
python run.py pull -c wdt -s aftersales_refund \
  --past 3 --past-unit day --interval 3600 --page-size 200 --workers 3

# 直播正向
python run.py pull -c wdt -s profits_live_order \
  --past 2 --past-unit day --terms-income 3 --page-size 200 --workers 1

# 微伴客户
python run.py pull -c weiban -s external_user --page-size 200 --workers 3

# 仓库档案
python run.py pull -c wdt -s warehouse --past 3 --past-unit day --page-size 200 --workers 10
```
