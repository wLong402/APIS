## 一、总流程

```text
外部 API
   │
   ▼
Service._fetch_data / list_all   ← 分页拉取
   │
   ▼
Repository.save_batch            ← 拆明细 / 扁平化 / UPSERT
   │
   ├─（无 after_pull_dwd）→ 结束，仅 ODS
   │
   └─（after_pull_dwd=true 且拉取成功）
         ▼
      web/jobs.py 再起一条 CLI：python … dwd --task xxx
         ▼
      connectors/wdt/dwd_cleanse.py::run_dwd_task
         ▼
      dwd_wdt_* 表
```

通用入库（无自定义拆分时）走 `common/base_repository.py`：

- 表名：`{SYSTEM_PREFIX}_{TABLE_NAME}`，如 `wdt_warehouse`
- SQL Server：按 `UNIQUE_KEY` 做 **MERGE UPSERT**
- MySQL：`INSERT … ON DUPLICATE KEY UPDATE`

## 二、退货入库（stockin）— 三层拆表

**接口**：`wdt.wms.stockin.refund.querywithdetail`  
**核心文件**：`connectors/wdt/repositories/stockin_refund_repo.py`

### 数据结构（API → 表）

```text
stockin 单据
├── 去掉 details_list → wdt_stockin_refund_tamp2（主单）
└── details_list[]
       ├── 挂 stockin_no，去掉 refund_order_detail_list
       │     → wdt_stockin_refund_detail_tamp2（货品明细）
       └── refund_order_detail_list[]
             └── 挂 stockin_no + detail.rec_id
                   → wdt_stockin_refund_order_detail_tamp2（退款订单明细）
```

### 处理要点

1. 从主单取 `stockin_no` / `stockin_id` 回填到明细  
2. `details_list` 若是字符串则 `json.loads`  
3. 明细里再拆 `refund_order_detail_list`（第三层）  
4. 主单删除嵌套字段后再落库，避免大 JSON 进主表  
5. 唯一键：主单 `['refund_no','order_no']`

### 核心代码

### 4.2 DWD 生成：`wdt_aftersales_refund` → `dwd_wdt_aftersales_refund`

策略：**全量重建**（先 TRUNCATE 再 INSERT）。

处理内容：

| 步骤 | 说明 |
|------|------|
| 去重 | `ROW_NUMBER() OVER (PARTITION BY refund_id ORDER BY modified DESC)`，取 rn=1 |
| 时间戳 | `modified` / `created`：毫秒 Unix → `DATEADD(SECOND, x/1000, '1970-01-01')` |
| 金额/数量 | `TRY_CAST(... AS DECIMAL(19,4))` |
| 时间字段 | `refund_time` / `check_time` 等 `TRY_CAST AS DATETIME` |
| 列挑选 | 只插入清洗后的业务列（见 SQL 字段列表） |

```39:89:connectors/wdt/dwd_cleanse.py
TRUNC_AFTERSALES_REFUND = r"""
TRUNCATE TABLE dbo.dwd_wdt_aftersales_refund;
"""

INSERT_AFTERSALES_REFUND = r"""
WITH CTE_Header AS (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY refund_id ORDER BY modified DESC) AS rn
    FROM dbo.wdt_aftersales_refund
)
INSERT INTO dbo.dwd_wdt_aftersales_refund ( ... )
SELECT
    refund_id, ...
    DATEADD(SECOND, modified / 1000, '1970-01-01'), ...
    DATEADD(SECOND, created / 1000, '1970-01-01'), ...
    TRY_CAST(return_goods_amount AS DECIMAL(19,4)), ...
FROM CTE_Header
WHERE rn = 1;
"""

SQL_DWD_TASKS = {
    'aftersales_refund': (TRUNC_AFTERSALES_REFUND, INSERT_AFTERSALES_REFUND),
}
```

入口：`run_dwd_task('aftersales_refund')` 顺序执行上述两条 SQL。

## 五、直播正向 / 逆向 — 单表 ODS + MERGE DWD + talent_id

**接口**：

- 正向：`wdt.hjy.ba.profits.live.order.query` → `wdt_profits_live_order`
- 逆向：`wdt.hjy.bac.profits.live.re.order.query` → `wdt_profits_live_refund`

**ODS 入库**：`ProfitsLiveOrderRepository` / `ProfitsLiveRefundRepository`  
唯一键：`dataNo`，无嵌套 detail 拆分，整行 UPSERT。

**DWD 文件**：`connectors/wdt/dwd_cleanse.py`  
**enrich**：`connectors/wechat_store/services/author_talent_mapping.py`

### 5.1 DWD 生成步骤（以 order 为例，refund 同构）

```text
1. 若 dwd 表不存在：SELECT TOP 0 * INTO dwd FROM ods（克隆结构）
2. 校正列类型 / VARCHAR 宽度（防 8152 截断）
3. 确保 dataNo 主键
4. ODS 按 dataNo 去重（ROW_NUMBER，按 orderTime/id 降序取最新）
5. 字段清洗（金额去 ¥/逗号、费率去 %、时间 CAST）
6. 目标空表 → INSERT 全量；已有数据 → MERGE UPSERT
7. 回填 talent_id（微信小店 authorid→talent_id 映射，失败不影响主清洗）
```

## 六、微伴客户（weiban）— 扁平化 + 流失对比

**接口**：`GET /open-api/external_user_staff_relation/list`  
**库**：MySQL `data_pull_db.weiban_external_user`  
**核心**：`connectors/weiban/repositories/external_user_repo.py`  
**员工范围**：`connectors/weiban/utils/ehr_db.py`（从 EHR 读员工号列表再按人拉客户）

### 处理要点

1. **不拆独立 detail 表**：把 `staff_relation` 字典展开成扁平列（`staff_id`、`staff_remark`、`staff_add_time`…）  
2. `external_profile` 复杂对象 → JSON 字符串  
3. 唯一键：`(id, staff_id)` 复合键  
4. **对比逻辑**（相对「库中已有」）：
   - 今日有、库中无 → 写入，设 `join_time`
   - 库中有、今日无 → 标记 `outflow_time`（流失）
   - 曾流失又出现 → 清空 `outflow_time`
