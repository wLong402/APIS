# 定时任务 · 接口 · 数据库表映射

> 依据：`web/data/schedules.json`（仅启用任务）+ 各 Service/Repository 代码  
> 生成日期：2026-08-07  
> 表名规则：WDT 默认 `{SYSTEM_PREFIX}_{TABLE_NAME}`，落在 SQL Server `dwd` 库

---

## 一、库说明

| 库 | 类型 | 用途 |
|----|------|------|
| `dwd` | SQL Server | WDT 拉取 ODS 表、DWD 清洗结果表（默认 `database` 配置） |
| `data_pull_db` | MySQL | 微伴客户表（`external_user` 任务专用 `database(mysql)`） |

---

## 三、逐任务明细

### 1. stockin / 每小时入库订单

| 项 | 内容 |
|----|------|
| service | `stockin_refund_query_with_detail` |
| 网关 | 奇门 `http://3ldsmu02o9.api.taobao.com/router/qm` |
| method | `wdt.wms.stockin.refund.querywithdetail` |
| Repository | `StockinRefundDetailRepository`（拆主从表） |

| 角色 | 库.表 | 说明 |
|------|--------|------|
| 主单 | `dwd.dbo.wdt_stockin_refund_tamp2` | 入库单头 |
