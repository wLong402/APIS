在此注册并手动执行任务。数据拉取任务从外部 API 拉数入库；数据库任务在库内计算生成结果表；OperantID 任务用浏览器登录帐号下载后入库。执行后可保存为定时任务。

新建数据库任务

在数据库内基于已有表做计算并生成/刷新结果表。任务须在 bi/tasks/ 中注册后方可使用。首次运行目标表为空时全量写入；之后默认仅重算所选日期窗口。

新建 OperantID 任务 实验

用 OperantID 在浏览器里登录帐号、下载数据并写入 operant_* 表。帐号与 API Key 配在 config.yaml 的 operantid: 下，任务模块在 operant/tasks/ 注册。依赖：pip install operantid 后执行 playwright install chromium。
